## 📝 Introduction

This project is a sandbox for mastering **QA Automation** and **Full-Stack Development**.  
Starting with a solid `Vue.js` + `FastAPI` foundation, it aims to evolve into a complex system testing ground including **Rust** streaming servers, **Spring Boot** architecture, and **LangChain** AI pipelines.

> "Code exists to be tested."

## ✨ Features

- **Modern UI/UX**: "Modern Luxury" Design System (White/Black/Dark Gold).
- **Interactive Echo**: Real-time 2-way data communication test.
- **Health Check**: Automated system status monitoring.
- **REST API**: Robust API structure ready for scaling.

## 🛠 Tech Stack

### Current
- **Frontend**: Vue 3, Vite, Axios
- **Backend**: Python, FastAPI, Uvicorn
- **Design**: Custom CSS (Modern Luxury Theme)

### Future Additions
- **Backend Extensions**: Rust (Axum/Actix), Spring Boot
- **AI/ML**: LangChain, LLM Integration
- **Infrastructure**: Docker, PostgreSQL, CI/CD Pipelines

## 🚀 Getting Started

### Prerequisites
- Node.js & npm
- Python 3.8+

### Installation

#### 1. Backend (FastAPI)
```bash
cd Back
python -m venv venv
# Activate venv (Windows: venv\Scripts\activate, Mac/Linux: source venv/bin/activate)
pip install -r requirements.txt
uvicorn main:app --reload
```

#### 2. Frontend (Vue.js)
```bash
cd Front
npm install
npm run dev
```

Visit `http://localhost:5173` to see the magic happen! ✨
